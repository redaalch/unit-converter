Implemented features

  • Temperature: convert between Celsius (C), Fahrenheit (F), and Kelvin (K). Reject invalid units, non-finite values, and temperatures below absolute zero.
  • Length: convert between meters (m), kilometers (km), and miles (mi). Reject negative lengths and unknown units.
  • Automated checks: pytest tests cover normal conversions, boundaries, and invalid inputs. GitHub Actions runs the suite on pushes and Pull Requests.

Local setup

Use Python 3.12. Clone the repository, create a virtual environment, and install the test dependency:

git clone https://github.com/redaalch/unit-converter.git
cd unit-converter
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

On Windows, create the environment with py -3.12 -m venv .venv. Activate it with .venv\Scripts\activate.bat in Command Prompt or .\.venv\Scripts\Activate.ps1 in PowerShell.

Use the converters

From the repository root, start Python with python, then run:

from unit_converter.temperature import convert_temperature
from unit_converter.length import convert_length

print(round(convert_temperature(0, "C", "F"), 2))
print(convert_length(1, "mi", "m"))

The examples print 32.0 and 1609.344. Use exit() to return to the terminal.

Run the tests

With the virtual environment active, run the complete suite from the repository root:

python -m pytest -q

Test files are in tests/. The conversion modules are in unit_converter/.
